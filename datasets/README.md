# `datasets/` — data root

This folder is the default **data root** (`paths.data_root` in
`configs/benchmark_v1.yaml`, overridable with `OSB_DATA_ROOT`). On Killarney
point it at scratch or project storage (see `slurm/env.sh`). Everything
below except this README and `manifests/` is generated by the pipeline and is
git-ignored. See [`../DATASETS.md`](../DATASETS.md) for what each source is.

```text
datasets/
├── manifests/                 # Small, versioned manifests (committed)
├── raw/<source>/              # Downloaded originals (git clones, zips, xlsx)
│   └── pmc_harvest/           #   hits.jsonl + refmap/<PMCID>.json
├── cache/
│   ├── pubmed.sqlite          # PMID -> parsed PubMed record (resumable)
│   ├── openalex.sqlite        # OpenAlex fallback cache
│   └── europepmc/<PMCID>.xml.gz
├── interim/
│   ├── <source>/reviews.parquet, records.parquet   # canonical schema
│   ├── enrich/review_pmids.parquet, doi_pmids.parquet
│   └── pools/<review_id>.json # Tier-1/Tier-2 candidate pools
├── processed/                 # merged, de-duplicated, text attached
│   ├── reviews.parquet  records.parquet  build_summary.json
├── splits/                    # families, split assignment, purged records
│   ├── splits.parquet  records.parquet  audit.json
└── frozen/<benchmark>/        # open_sr_bench, open_sr_bench_extended,
    ├── tiers.parquet          #   titan_test, prospective
    ├── review_totals.parquet
    └── manifest.json          # counts + SHA-256 per tier + leakage audit
```

Disk budget for a full build: ~40 GB raw/cache, ~15 GB processed.
